\# Exam Malpractice Detection System



A web-based system developed using Java, JSP, Servlets, and Apache Tomcat to detect exam malpractice based on student activity (like tab switching, multiple logins, etc.).



\## Features

\- Student login

\- Admin login

\- Online exam module with timer

\- Malpractice detection (tab switching, multiple logins, IP checks)

\- Activity logs for admin review



\## Technology Stack

\- Java

\- JSP \& Servlets

\- MySQL

\- Apache Tomcat

\- Git \& GitHub



\## How to Run

1\. Clone the repository.

2\. Open project in Eclipse.

3\. Add Tomcat server (9 or 11) in Eclipse.

4\. Run project on server.

5\. Open in browser: `http://localhost:8080/ExamMalpracticeDetection`
